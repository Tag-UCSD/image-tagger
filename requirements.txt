# image-tagger backend runtime requirements
#
# Pinning policy: compatible-release (`~=X.Y`) on direct deps so patch and
# minor upgrades flow in but new majors don't surprise us. For full
# reproducibility (CI parity, prod parity), generate a hashed lockfile:
#
#     pip install pip-tools
#     pip-compile --generate-hashes requirements.txt -o requirements.lock
#
# Then have CI / Docker `pip install -r requirements.lock` instead.
#
# This file is consumed by .github/workflows/ci.yml — when present, the
# workflow's hand-rolled fallback `pip install` list is skipped. See also
# `requirements-install.txt` (separate concern: host-side install guard
# scripts only).

# ─── PyTorch CPU-only wheel index ────────────────────────────────────────
# The default `torch` wheel on PyPI bundles ~700MB of CUDA libraries we
# don't need on CI runners or non-GPU dev boxes. The CPU-only index
# delivers a ~150MB wheel instead. Remove this line if you provision GPU
# hosts and want CUDA wheels.
--extra-index-url https://download.pytorch.org/whl/cpu
